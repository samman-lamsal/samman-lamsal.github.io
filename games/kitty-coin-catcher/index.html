About Kitty Coin Catcher

Kitty Coin Catcher is a released HTML5 arcade game on itch.io. Players drag the bucket with the cursor to catch falling coins.

Key features

Simple drag-to-catch controls
HTML5 browser play
Cute casual arcade theme
Score-chasing gameplay

Developer

Kitty Coin Catcher is part of the MASARP Studio portfolio by independent game developer Samman Lamsal.
