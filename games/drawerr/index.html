About Drawerr

Drawerr is a Windows drawing game released on itch.io and made with Unity. Players receive random words and draw them before time runs out.

Key features

Random drawing prompts
Timed creativity-focused rounds
Cozy wooden and doodle-inspired art direction
Made with Unity for Windows

Developer

Drawerr is part of the MASARP Studio portfolio by independent game developer Samman Lamsal.
