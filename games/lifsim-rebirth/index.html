About LifSim: Rebirth

LifSim: Rebirth is a life-simulation project by MASARP Studio focused on choices, personal growth, goals and the long-term progression of a virtual life.

Key features

Choice-driven life progression
Goals, growth and personal milestones
Study, work, relationships and home themes
Long-form simulation structure

Developer

LifSim: Rebirth is part of the MASARP Studio portfolio by independent game developer Samman Lamsal.
