About CARLRUN

CARLRUN is a fast-paced first-person parkour shooter on Playgama where movement is survival. Players wall-run, slide, double-jump, fight rogue mechs and build combo multipliers across distinct arenas.

Key features

Wall-running, sliding and double-jumps
Fast FPS combat against rogue mechs
Combo multiplier for rapid damage-free eliminations
Arenas including Urban Bunker and Magma Core

Developer

CARLRUN is part of the MASARP Studio portfolio by independent game developer Samman Lamsal.
