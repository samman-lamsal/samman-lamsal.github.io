About PinsDrawp

PinsDrawp is a timing-focused arcade puzzle where players shoot numbered pins onto a rotating wheel without colliding with pins already attached.

Key features

Normal Mode with 1,200 progressively harder levels
Endless Mode for high-score survival
Rotation speed and direction changes as difficulty rises
Spin & Win rewards and separate leaderboards

Developer

PinsDrawp is part of the MASARP Studio portfolio by independent game developer Samman Lamsal.
