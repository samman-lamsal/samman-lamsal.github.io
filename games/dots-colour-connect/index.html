About Dots Colour Connect

Dots Colour Connect is a color-connection puzzle game by MASARP Studio. Players connect matching dots and solve compact boards designed for quick, readable sessions.

Key features

Color-matching connection puzzles
Compact board-based levels
Simple touch-friendly interaction
Built for quick casual sessions

Developer

Dots Colour Connect is part of the MASARP Studio portfolio by independent game developer Samman Lamsal.
