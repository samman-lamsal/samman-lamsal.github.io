About Stick Wars Legend

Stick Wars Legend is a 2D stick-war strategy/action game featuring unit selection, base defense, resources, enemy waves and combat abilities.

Key features

Multiple unit types including Soldier, Gunner, Giant, Sniper, Bomber, Medic, Knight, Mage, Assassin and Flamer
Base protection and escalating enemy waves
Money/resources, health bars and level progression
Combat abilities including damage and split mechanics

Developer

Stick Wars Legend is part of the MASARP Studio portfolio by independent game developer Samman Lamsal.
