# MASARP Studio website

Professional static website for **MASARP Studio**, the independent game label of **Samman Lamsal**.

## Deploy
Upload the CONTENTS of this folder to the root of the `samman-lamsal.github.io` repository. GitHub Pages should publish from `main` / `(root)`.

## When masarpstudio.com is connected
Replace every occurrence of `https://samman-lamsal.github.io` with `https://masarpstudio.com`, then add a `CNAME` file containing `masarpstudio.com`.

The current site intentionally does not invent store URLs. Add official play/store links and real screenshots when you have them ready.
